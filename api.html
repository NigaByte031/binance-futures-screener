راهنمای API

یک API عمومی و فقط-خواندنی (read-only) برای دریافت لیست قراردادهای پپچوال USDT-M بایننس به همراه تغییرات ۲، ۶، ۱۲ و ۲۴ ساعته. نیازی به کلید یا ثبتنام نیست؛ از هر زبان یا مرورگری میشود فراخوانی کرد.

آدرس این نصب

هر کسی که میخواهد از API استفاده کند، درخواستهای خود را دقیقاً به این آدرس بزند:

/api/v1

    

  


  

    
GET تنهاهیچ عملیات نوشتن یا تغییری وجود ندارد

    
بدون احراز هویتنه توکن، نه API key

خطاها

  
همه خطاها با کد HTTP مناسب و همان قالب ok: false برگردانده میشوند.

  

    
کدHTTPعلت

      
INVALID_PARAM400پارامتر نامعتبر یا خارج از محدوده

      
INVALID_SYMBOL400نام نماد بدفرمت

      
SYMBOL_NOT_FOUND404نماد وجود ندارد یا غیرفعال است

      
NOT_FOUND404آدرس API وجود ندارد

      
UPSTREAM_ERROR502بایننس در دسترس نیست یا منطقه مسدود است

      
INTERNAL_ERROR500خطای داخلی؛ جزئیات در لاگ سرویس

    

  


  
نکات فنی

  

    
تازگی داده: قیمت هر ۱۵ ثانیه و کندلهای ۱۵ دقیقهای هر ۳ دقیقه یکبار از بایننس گرفته میشود. تمام کلاینتها از یک کش مشترک استفاده میکنند، پس ۱۰۰ کاربر همزمان تنها یک اسکن از بایننس ایجاد میکند.

    
محاسبه: تغییر ۲/۶/۱۲ ساعته از کندل بسته ۱۵ دقیقه متناظر حساب میشود (len-1-round(h/0.25)) و تغییر ۲۴ ساعته مستقیماً از priceChangePercent بایننس است — دقیقاً مانند صفحه اصلی.

    
دسترسی: API عمداً عمومی و بدون کلید است تا هر کسی بتواند از آن استفاده کند. فقط GET و OPTIONS پشتیبانی میشود و هیچ عملیات نوشتنی وجود ندارد.

    
محدودیت: حداکثر limit=500 در هر درخواست. برای گرفتن همه نمادها از صفحهبندی (offset) یا endpoint سبک /symbols استفاده کنید.
